Snonyx TV est un lecteur IPTV pour téléphone, tablette, Chromecast avec Google TV et téléviseurs Android.
Il lit **ton propre abonnement** (listes M3U ou identifiants Xtream) : aucune chaîne ni aucun contenu n'est fourni.

Cette page sert uniquement à distribuer l'application aux testeurs. Un compte Snonyx (essai gratuit) est demandé
au premier lancement.

## Installer sur un téléphone ou une tablette

1. Ouvre le lien **Télécharger la dernière version** ci-dessus depuis le téléphone.
2. Ouvre le fichier `SnonyxTV.apk` téléchargé.
3. Si Android le demande, autorise ton navigateur à installer des applications, puis appuie sur **Installer**.

## Installer sur Chromecast avec Google TV ou une TV Android

1. Sur la TV, installe l'application **Downloader** (par AFTVnews) depuis le Play Store.
2. Autorise Downloader à installer des applications :
   - Paramètres › Système › À propos : appuie 7 fois sur **Build du système d'exploitation Android TV**
     (les options pour les développeurs s'activent) ;
   - Paramètres › Applications › Sécurité et restrictions › **Sources inconnues** › active **Downloader**.
3. Ouvre Downloader et tape le code **`8526116`**.
4. L'APK se télécharge : appuie sur **Installer**, puis **Ouvrir**.

## Mises à jour

Une fois installée, l'application se met à jour d'elle-même : quand une nouvelle version est publiée ici, un bouton
de téléchargement apparaît sur l'accueil (sur TV : la pastille « Mise à jour disponible »). Plus besoin de Downloader.

## Un souci ?

Dans l'application : **Paramètres › Aide et testeurs** (discussion avec l'administrateur, signalement de bug avec
capture, canal général des testeurs).
